 💰 Smart Expense Tracker

A full-stack web application to manage and track daily expenses and income efficiently. This project helps users monitor spending habits, categorize transactions, and gain financial insights.

🚀 Features
🔐 User Authentication (Login / Register with JWT)
➕ Add, Edit, Delete Expenses
💵 Track Income & Expenses
📊 Dashboard with Charts (Expense Analysis)
🗂️ Category-wise Expense Tracking
📅 Date-wise Filtering
📈 Monthly & Daily Reports
📱 Responsive UI Design


🛠️ Tech Stack
Frontend:
React.js
CSS / Bootstrap
Axios

Backend:
Node.js
Express.js

Database:
MongoDB (Mongoose)

Other Tools:
JWT Authentication
Chart.js (for data visualization)
